# Game Elements

This folder documents game elements in consolidated groupings.

- `factions-armies.md`: Empires and armies in the current game
- `laws-events.md`: Enactable laws and standard events
- `law-events.md`: Law enactment choice events
- `improvements-economy.md`: Improvements catalog and economy notes
- `battlefronts-cohesion.md`: Battle defaults and cohesion values
- `resources-commodities.md`: Commodity tiers and floor prices
