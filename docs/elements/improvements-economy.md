# Improvements and Economy

## Overview
Improvements are the coalition's long-term infrastructure projects. They consume requisition to build, require sustainment, and apply ongoing outputs or bonuses. The improvements system features 8 specialized branches with tiered progression, where empires must complete lower-tier improvements to unlock higher tiers.

## Improvement Suggestion System
Each empire maintains a queue of 3 suggested improvements at any given time. When an empire accepts and begins building an improvement, a replacement suggestion is immediately generated from available improvements. The suggestion system allows for strategic flexibility - the same improvement can be suggested multiple times to an empire, even if they're already building it or have already requested it elsewhere.

## Requisition System
Improvements are built using **requisition** - a coalition resource produced through the economy system:
- Requisition is generated by converting coalition stockpiles through batch processing
- Starting requisition: 500 units for initial improvement construction
- Bank rollover: when commodity bank reaches 25,000 units, it converts to 24 requisition

## Improvement Catalog (Current Game)

### Tier System
Improvements are organized in tiers (T1, T2, T3) within branches:
- **T1**: Basic infrastructure, available immediately
- **T2**: Advanced mega-structures requiring 2 completed T1 improvements per empire
- **T3**: Transcendent projects requiring 2 completed T2 improvements per empire

## Improvement Behavior
- **BUILDING**: progresses by coalition construction each tick (default 4 build progress)
- **ACTIVE**: sustainment is paid and outputs/modifiers apply
- **DEGRADED**: sustainment failed, no production until restored
- **Construction capacity limit**: total BUILDING capacity cannot exceed 5

## Economy Notes
- Coalition procurement budget: 100 credits per tick (default config), with a fixed 5,000 credit starting budget
- Sustainment buy orders use priority 800 and pay up to 2x market price
- Performance penalties apply when army needs fulfillment drops below 0.80

## Requisition Mechanics
- **Bank Threshold**: 1000 units needed in bank before conversion triggers
- **Bank Rollover**: When bank reaches 25,000 units, converts to 24 requisition
- **Batch Conversion**: Commodities convert to bank units based on tier (T1: 1000, T2: 100, T3: 10 units per commodity unit)
- **Batch Bonus**: Additional bank units granted per conversion batch
