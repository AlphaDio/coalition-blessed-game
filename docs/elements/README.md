# Game Elements

This folder documents game elements in consolidated groupings.

- `factions-armies.md`: Empires, ideologies, and armies
- `laws-events.md`: Laws, law events, and narrative events
- `improvements-economy.md`: Improvements, tiers, and market integration
- `battlefronts-cohesion.md`: Battlefronts and cohesion tiers
- `resources-commodities.md`: Commodity tiers and resource definitions
